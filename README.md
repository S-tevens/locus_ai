# locus_ai
AI-driven cyber risk detection for smart city traffic and emergency infrastructure — classifies live telemetry from traffic cameras, signal controllers, ambulance trackers, and dispatch servers to catch DDoS, port scans, brute-force logins, GPS/MAC spoofing, and command-injection attacks targeting ambulance signal preemption. Stack: FastAPI, scikit-learn, WebSockets, React, Leaflet, Python.
